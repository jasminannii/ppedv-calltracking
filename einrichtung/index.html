Calltracking einrichten

Zum Dashboard
1
Agent herunterladen ppedv-calltracking-agent.zip
2
Auf den Desktop entpacken

ZIP rechtsklicken → „Alle extrahieren …“ → Ziel: Desktop. Ältere Version einfach überschreiben.

3
Installieren.cmd doppelklicken

Im Ordner Linkus Wahlversuche Dashboard\linkus-dashboard. Warnt Windows: „Weitere Informationen“ → „Trotzdem ausführen“.

4
Team-Code eingeben – fertig

Die Nebenstelle wird aus Linkus erkannt. Der Agent läuft unsichtbar und startet mit Windows.

Gesendet werden nur Anrufdaten (Zeit, Nummer, Ergebnis, Dauer) – keine Linkus-Logs, keine Passwörter. Eigene Live-Ansicht und Powerdialer weiter unter http://localhost:8765.
